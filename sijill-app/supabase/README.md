# تهيئة Backend سِجِلّ

تستخدم لوحة الإدارة مسار `/admin`، وقاعدة البيانات تفرض الصلاحيات عبر Row Level Security. إخفاء اللوحة أو أزرارها ليس هو الحماية؛ سياسات Supabase هي التي تمنع الوصول غير المصرح به.

## الأدوار

- `owner`: مالك المنصة (Super Admin). وحده يعيّن الأدوار، ويعدّل أو يحذف ملفات الأشخاص، ويرى سجل الحركات، ويدير الإشعارات العامة وإعدادات الموقع.
- `editor`: يرى محتوى المراجعة، وينشئ المحتوى ويعدّل ما يملكه. لا يستطيع حذف السجلات أو تعديل محتوى الآخرين. لا يسمح له بنشر محتواه إلا بعد اجتياز مراجعة الذكاء الاصطناعي.
- `member`: مساهم مسجل؛ ينشئ محتواه ويرى محتواه الخاص والمحتوى المنشور.

بيانات الدور محفوظة في `public.sijill_user_roles`، ولا يستطيع المستخدم تعيين دوره بنفسه. سجل النشاط يحفظ نوع العملية وأسماء الحقول المتغيرة فقط، ولا ينسخ نصوص الشهادات أو الأدلة إليه.

## تشغيل الترحيلات

1. افتح Supabase Dashboard ثم مشروع سِجِلّ ثم **SQL Editor**.
2. إذا لم تكن قد جهّزت قاعدة الإدارة من قبل، شغّل ملفات `migrations` بالترتيب الزمني لأسمائها.
3. إذا كانت قاعدة الإدارة والوسائط والربط مجهزة مسبقاً، شغّل أي ترحيل شهادة لم تطبقه بعد، ثم شغّل `20261009_000001_admin_dashboard_controls.sql` أخيراً. يضيف الترحيل الأخير صلاحيات المالك الحصرية لتعديل/حذف ملفات الأشخاص، وملاحظات مراجعة طلبات التوثيق، وإعداد خلفية الموقع، وإحصاء الرسم البياني حسب سنة الحدث.
4. لا يحذف هذا الترحيل أي شهادة موجودة. إذا اكتشف شهادات مكررة للحساب والموضوع نفسه، سيتوقف ويطلب مراجعتها قبل فرض القيد.
5. من **Authentication → Users** انسخ `UUID` لحسابك.
6. في SQL Editor نفّذ الاستعلام التالي بعد استبدال النص بين علامتي الاقتباس بمعرّف حسابك:

```sql
insert into public.sijill_user_roles (user_id, role)
values ('ضع-UUID-حسابك-هنا', 'owner')
on conflict (user_id) do update set role = 'owner';
```

بعد ذلك سجّل الدخول إلى الموقع وافتح `/admin`. يمكن لاحقاً تعيين محرر من SQL Editor:

```sql
insert into public.sijill_user_roles (user_id, role, assigned_by)
values ('UUID-المحرر', 'editor', 'UUID-المالك')
on conflict (user_id) do update set role = 'editor', assigned_by = excluded.assigned_by;
```

لا تشارك مفاتيح Supabase السرية أو روابط جلسة تسجيل الدخول. يكفي UUID لحساب المستخدم، وهو ليس كلمة مرور.

## ما هو متاح الآن

توفر لوحة الإدارة ملخص الإحصاءات ومراجعة طلبات التوثيق، وفهرس القضايا والملفات والشهادات، وتقارير قابلة للطباعة، ومراسلات الحسابات، والإشعارات العامة، وإعدادات المالك. إرسال رابط استعادة كلمة المرور يستخدم تدفق Supabase ولا يكشف كلمة مرور المستخدم للمشرف.

صلاحيات قاعدة البيانات هي خط الدفاع الفعلي: يمنع RLS المحررين والمستخدمين من تعديل ملفات الأشخاص أو حذفها، حتى إذا حاولوا استدعاء Supabase مباشرة دون واجهة الإدارة.
